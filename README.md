# vesicle-seg

**Synaptic-vesicle segmentation on synthetic EM-like volumes.**

Spec: [`SPEC.md`](SPEC.md).

## Visual

![Synthetic EM overlay panel: raw, ground truth, threshold, residual 3D U-Net](docs/overlay_panel.png)

Also: [`docs/overlay_unet.png`](docs/overlay_unet.png). Regenerated by `make demo` / `configs/ci.yaml`.

```text
Raw EM-like volume → Zarr → adaptive overlapping chunks
  → residual 3-D U-Net (dropout; Dice + focal)
  → stitched prediction → overlays + vesicle density maps
```

## Demo / Results

Metrics from a `make demo` run on `configs/ci.yaml` (2026-09-14): `n_volumes=6`, shape
`8x64x64`, voxel `(40, 4, 4)` nm, 8 epochs, `leakage_ok=true`. If this table disagrees with
[`reports/metrics.example.json`](reports/metrics.example.json) or a fresh
`reports/metrics.json`, trust the JSON, since that is what the code writes.

| Model | Dice | IoU | F1 | pixel acc |
|-------|------|-----|----|-----------|
| threshold + morphology | 0.226 | 0.132 | 0.226 | 0.960 |
| resunet3d (8 epochs, CPU) | 0.460 | 0.304 | 0.460 | 0.973 |

The residual net beats the threshold floor on Dice, IoU and F1. Pixel accuracy moves by
about a point across the two rows while Dice moves by 23, because background dominates the
volume. Torch is unseeded, so the U-Net row shifts between runs; the threshold baseline
reproduces exactly. Density per um^3 is a count over a ~0.021 um^3 crop, which makes it a
pipeline check.

Walkthrough (~60–90s after install):

1. `make generate` writes synthetic ssEM-like cubes (`8x64x64`). Vesicles are 40-60 nm blobs; mitochondria-like ovals are unlabeled distractors.
2. `make demo` trains the residual 3D U-Net and the threshold baseline. The split is by `volume_id`, with raw-hash leakage checks. Inference uses overlapping chunks and writes only the inner region, which avoids double-counting across tile seams.
3. Open `reports/overlay_panel.png` for the raw, ground-truth, threshold and U-Net panels.
4. Open `reports/metrics.json` for Dice, F1, IoU and density per um^3.
5. Optional: `make serve` starts a local viewer at `http://127.0.0.1:8765/viewer/`.

## Run Locally

```bash
git clone https://github.com/kladak/vesicle-seg.git
cd vesicle-seg
python -m pip install -e ".[dev]"
# CPU torch is enough. If the wheel is missing: pip install torch --index-url https://download.pytorch.org/whl/cpu

make generate
make demo          # configs/ci.yaml: residual 3D U-Net plus threshold baseline
make serve         # optional viewer at http://127.0.0.1:8765/viewer/
make test          # what CI runs, plus make train-ci
```

No network. No lab data.

## Data

`vesicle_seg/synth/generate.py` builds ssEM-like volumes with 40-60 nm vesicle blobs at a
`(40, 4, 4)` nm voxel size, plus unlabeled mitochondria-like distractors.
[`PROVENANCE.md`](PROVENANCE.md) covers where the problem came from and cites the public EM
tooling the design references.
